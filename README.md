# IELTS за 3 дня

Интерактивная программа подготовки к IELTS на 15–17 ноября 2026 (экзамен 18 ноября) с упором на Writing и Speaking.

Собрана из материалов двух Telegram-каналов:

- [Violetta Erdley | IELTS](https://t.me/erdleyielts) — основа: разборы Writing Task 1 (процесс, естественное развитие, карты), эссе Band 8.0, образец Speaking Part 1, лексика.
- [VBoostLab](https://t.me/vboostlab) — дополнение: прогнозы заданий, разбор Venus flytrap, фразы для Speaking, словари.

- [IELTS Advantage](https://www.ieltsadvantage.com/) — структуры для типов заданий, которых нет в каналах: графики Task 1 и пять типов эссе Task 2.

У каждого блока в программе указан источник.

## Как открыть

Откройте `index.html` в браузере — это один файл без сборки и без сервера. Прогресс по плану и черновики эссе сохраняются в браузере.

Проверка у Claude, диктовка и чат работают без API-ключа, но только когда страница опубликована как артефакт на claude.ai (возможности `sample` и `dictation`). В локальном `index.html` эти кнопки отключены.

## Что внутри

| Раздел | Содержание |
| --- | --- |
| План | Три дня по задачам с временем и отметками о выполнении |
| Writing Task 1 | Шаблоны для всех типов: графики (line, bar, pie, table), два графика, процессы, карты; готовые ответы и чек-лист |
| Writing Task 2 | Эссе Band 8.0 с выделенными фразами и шаблоны шести типов эссе |
| Speaking | Образец Part 1, формула ответа, идиома, фразы, тренировка с таймером |
| Слова | Карточки по всем фразам и словам из постов |
| Тренажёр | Письмо на время со счётчиком слов и сравнением с образцом |
| Claude | Проверка эссе и устных ответов, диктовка, чат-репетитор — только в артефакте на claude.ai |
| Источники | Что из каналов вошло и что открывается только в Telegram |

## Чего здесь нет

PDF, аудио и HTML-файлы VBoostLab (прогнозы Speaking и Writing, большие списки слов, пробные Reading и Listening) и часть видео Эрдли доступны только в приложении Telegram. В программе на них стоят ссылки.

## Разработка

Исходник — `src/app.html`. `index.html` — тот же файл, обёрнутый в `<!doctype html>`:

```sh
{ printf '<!doctype html>\n<html lang="ru">\n<head>\n<meta charset="utf-8">\n<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">\n</head>\n<body>\n'; cat src/app.html; printf '</body>\n</html>\n'; } > index.html
```
